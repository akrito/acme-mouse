#+TITLE: README

This fork includes modifications to keep up with the changes to the ~cl~ package, as well as modifications to more closely match acme's behaviors.  It also implements it as a minor mode, ~acme-mouse-mode~, with a global option.
* Modified Behavior
:PROPERTIES:
:ID:       dda3435f-7e79-4505-aa2b-ef8634b3dd1c
:END:
** Mouse-3
*** acme-search
:PROPERTIES:
:ID:       cd6ce98f-6e3d-4f75-babd-9b624c853580
:END:
The ~acme-search~ function (single click on ~mouse-3~) now resets the point if you click on a different word, and keeps the same region if you click within it. [[https://www.reddit.com/r/emacs/comments/1coumhm/elisp_determine_if_mouse_posn_is_within_region/l3gqj4c/][Thanks u/Slow-Mammoth7380!]]
*** Dragging
Dragging with ~mouse-3~ now sets region and searches for said region.  If the next ~mouse-3~ click is inside the new region, it does /not/ change the search text.
** Mouse-2
:PROPERTIES:
:ID:       da7c7af9-22ec-4d38-abd9-7b86a761d284
:END:
Clicking ~mouse-2~ without chording and without dragging now either calls ~eval-defun~ or clicks a button/link.  If ~mouse-2~ is drug, region is set, and then ~eval-region~ is called.
